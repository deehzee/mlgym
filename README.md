## Cloning

`d2l/d2l-neu` is a git submodule (large, about 1 GB checked out) and is not fetched by a
plain `git clone`. To get it:

    git submodule update --init d2l/d2l-neu      # in an existing clone
    git clone --recurse-submodules <url>         # or at clone time

See [`d2l/README.md`](d2l/README.md) for details.
